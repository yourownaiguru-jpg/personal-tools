# Guide

## Using it

1. Type a name. Roman letters work — double a vowel for a long one (`aa`,
   `ee`, `oo`), so "Raam" gives a long first vowel and "Rama" doesn't. You
   can also type directly in Tamil, Kannada, Telugu, Malayalam,
   Devanagari, Bengali, Gujarati, or Odia.
2. Pick a language. This decides which timeline of eras you see, and
   which modern script the "now" column uses in the letter map.
3. Pick a point on the timeline. The plate re-renders in that era's
   script immediately.
4. **Download image** saves a PNG of the plate, styled for whichever
   surface (stone / copper plate / palm leaf) is selected. **Copy link**
   copies a URL that reproduces this exact name, language, era, and
   surface for anyone you send it to.

## "Authentic" vs. "Approximation"

Every era is tagged one of two ways, and the tag means something specific:

- **Authentic** — that era's actual script has its own Unicode encoding
  (Brahmi, Grantha, Siddhaṃ, Śāradā, Bhaiksuki, Nandinagari), so your name
  is set in that script's real letters, code point for code point.
- **Approximation** — the era's actual script (Vatteluttu, the Kadamba
  hand, early Telugu-Kannada) has no Unicode encoding yet, so the closest
  living descendant stands in instead. The era's note always says which
  one and why.

Neither label is a value judgment on the era — some of the most
historically important scripts (Vatteluttu, Kadamba) simply haven't been
digitized. The label just tells you which kind of "then" you're looking
at.

## Why "Ram" and "Rama" don't look the same

Spellings follow the script's own rules, not English pronunciation. A
name typed as `Ram` ends on a bare consonant with its vowel explicitly
killed (a virama mark) — that's the literal spelling. Type `Rama` for the
classical, vowel-ending form. Neither is "wrong"; they're different words
to an Indic script, the way "Rob" and "Robbie" are different words in
English even though both come from "Robert."

## Why some sounds change between eras

Some sounds a modern language uses didn't exist in an older script's
inventory — most commonly the short/long e and o distinction, which
several ancient and medieval scripts don't make at all. Where that
happens, the nearest sound the script *does* have stands in, the same way
a scribe of the time would have written it. The caption under the plate
always says when this happens for the era you're viewing.

## If a name doesn't look right

- Check the language selector matches what you intended — the same roman
  spelling can parse differently depending on it (e.g. Tamil has no
  aspirated consonants, so "Khamala" and "Kamala" render identically in
  Tamil, correctly).
- Very unusual consonant clusters or a language's rarer sounds may not
  have a dedicated key in an older script's table; the nearest sound
  substitutes, same as above.
